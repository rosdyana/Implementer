# Implementation (from the implementer plugin)
After a plan is approved, carry it out with the `implementer:implement` skill: it delegates the code edits to the `implementer:implementer` subagent on the configured model, then reviews the diff and runs the final checks on the main model. Do this without being asked; the user does not need to mention the implementer.
When you write a plan in plan mode, put this line near the top: "Execution: delegate via `implementer:implement`."
There are exactly two exceptions, and nothing else qualifies: (a) the project's CLAUDE.md marks the area as high-risk, or (b) the whole change is a single line. "I already know the content", "it's faster to do it myself", "the files are new" or "delegation overhead" are not exceptions. If you use an exception, say which one to the user before editing.
